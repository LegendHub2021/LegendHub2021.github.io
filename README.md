# legendofgamer.com

Single-page Coming Soon website for Legend.

## Safety boundaries

- No account credentials or private information belong in this repository.
- The website has one public route only.
- GoDaddy remains the registrar and DNS provider.
- Google Workspace MX and TXT records must not be changed during deployment.

## Local commands

```sh
npm install
npm run dev
npm run build
```

Pushes to `main` deploy through GitHub Pages after Pages is enabled for the repository.
